# Zomato Restaurants Analysis Dashboard

## Project Overview
This Power BI dashboard project analyzes Zomato restaurant data to generate insights related to restaurant ratings, online delivery, table booking, social media presence, and customer engagement. The dashboard provides interactive visualizations and KPI reporting for better business understanding.

---

## Dashboard Features

- Total Restaurants Analysis
- Average Restaurant Rating
- Online vs Offline Delivery Analysis
- Table Booking Availability
- Social Media Followers Insights
- Ratings Distribution
- Customer Engagement Metrics
- Interactive Filtering and Visualization

---

## Tools & Technologies Used

- Power BI
- DAX
- Data Cleaning
- Data Modeling
- Excel / CSV Dataset

---

## Key Insights

- Most restaurants do not provide table booking services.
- Online delivery is available for a smaller portion of restaurants.
- Social media platforms contribute significantly to restaurant engagement.
- Restaurant ratings vary across different categories and cities.
